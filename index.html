02 — พฤติกรรมการใช้จ่าย

WP & กระดานอีเวนต์

กระดานหลัก (Main) คือหัวใจของอีเวนต์ ส่วน Wheel และ Shop เป็นตัวเสริมที่คนแตะน้อยลงเรื่อยๆ และแทบไม่มีใครยอมจ่าย WP เพื่อรีเซ็ตกระดาน

WP ที่ใช้ แยกตามประเภทกระดาน

พฤติกรรมการรีเซ็ตกระดาน (Reset)

รีเซ็ตทั้งหมด 4,751 ครั้ง — เกือบทั้งหมดเป็นรีเซ็ตฟรี มีแค่ส่วนน้อยที่ยอมจ่าย 100 WP

รีเซ็ตฟรี (0 WP) — 4,541 ครั้ง · 95.6% รีเซ็ตเสียเงิน (100 WP) — 210 ครั้ง · 4.4%
การรีเซ็ตแบบจ่ายเงินรวมแค่ 21,000 WP = 0.37% ของ WP ทั้งหมด → ผู้เล่นไม่ยอมจ่ายเพื่อรีรอล สะท้อนว่ารางวัลบนกระดาน “ไม่คุ้มพอ” ให้ลุ้นซ้ำ

04 — สิ่งที่ควรทำต่อ

ข้อเสนอปรับปรุงรอบหน้า

เรียงตามลำดับความสำคัญ อิงจาก Feedback + ข้อมูลพฤติกรรมจริง แต่ละข้อผูกกับหลักฐานที่เจอในอีเวนต์นี้

P1 · ด่วน

รีบาลานซ์ราคาไอเทมแลกใหม่

ทบทวนราคาที่กระโดดแรง โดยเฉพาะคอสตูมพรีเมียม (เพชรแดง 150 → 300) ให้กลับมาใกล้เดิม หรือเพิ่ม value ให้สมราคา และเทียบราคากับ WP ที่ผู้เล่นหาได้จริง

หลักฐาน: Feedback ราคาแพง (เก็ท, แฟนเพจ) + paid conversion แค่ 12% + คนไม่ยอมจ่ายรีเซ็ต (0.37% ของ WP)

P1 · ด่วน

เพิ่มลิมิตการแลกไอเทมดีมานด์สูง

ปลดเพดาน “แลกได้ 1 ชิ้น” สำหรับของตีบวก (Belorb Stabilizer) และกุญแจ ให้แลกได้หลายชิ้น เพราะเป็นของที่คนต้องการมากที่สุด

หลักฐาน: Belorb Stabilizer = ของที่แลกมากสุด (26) แต่โดนลิมิต · Feedback คุณพีท

P2 · สำคัญ

ใส่แพ็คกุญแจเป็นรางวัลหลัก

เพิ่มแพ็ค/บันเดิลกุญแจ (Ominous Ruins, Crystal Hall, Memory Stone, Convent, Kepa) ให้เป็นแม่เหล็กของอีเวนต์ เพราะเป็นดีมานด์ที่พิสูจน์แล้วทั้งจากข้อมูลและคำขอ

หลักฐาน: กุญแจ = 42% ของการแลกทั้งหมด (60 ครั้ง) + คำขอตรงจากคุณบอมบ์

P2 · สำคัญ

อัปเดตพูลไอเทมให้ตรงแพทช์

เอาไอเทมตกแพทช์ออก เติมของใหม่ที่เข้าเกมแล้ว และปรับ Belorb Core Fragment : Goddess / Belorb Core : Goddess เป็นระดับ Celestial ตามคำขอ

หลักฐาน: Feedback ของตกแพทช์ (พีท, แฟนเพจ) + คำขอปรับ tier (ก็อต)

P3 · ทดลอง

ยกระดับ Monetization ของกระดานเสริม

Wheel/Shop มีคนแตะน้อย (9% / 3%) และแทบไม่มีใครจ่ายรีเซ็ต — ลองลดราคารีเซ็ต/ไอเทมกระดาน หรือเพิ่ม value ให้คนยอมจ่าย เพื่อดันฐาน paid user 103 คนให้ขยับขึ้น

หลักฐาน: Wheel เข้าถึง 8.9% · Shop 3.0% · paid reset 210 ครั้ง = 0.37% ของ WP
